# Proofbench

The public pages of Proofbench, an independent test lab for Confluence apps.

Proofbench installs every app that claims to answer one popular feature request, runs the same checks on each, and publishes what each app does and does not do. Makers can pay for deeper private reports and re-tests, never for results.

Site: https://world-wide-nodes.github.io/App_Testing_Lab/

Contact: proofbench.lab@proton.me
