About

An independent lab, paid by makers for depth, never for results

Proofbench tests look-alike Confluence apps against the same checks and publishes what each one does and does not do. Buyers read everything for free.

Independent

The lab is not affiliated with Atlassian or with any app maker. No maker decides which apps we test, which checks we run or what we write.

How the lab earns money

Makers can pay for deeper private reports and re-tests, never for results. They can buy a private full report, a re-test after a fix, or an earlier test of a new app. A paid re-test is published like any other, whatever it shows.

This site has no ads and no affiliate links, and the lab takes no money for a mention. Prices and rules for makers

Report a mistake

If you think a result is wrong, tell us which comparison, which app and which check, and what you saw. We look at it, correct it within three working days if we were wrong, and add a dated note to the page.

Write to proofbench.lab@proton.me.
