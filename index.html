Why you can trust the results

The method

How a comparison is made

The same steps, in the same order, for every comparison.

  1. Pick a request

    A popular feature request on Atlassian's public tracker that several store apps claim to answer.

  2. Tell the makers

    Each maker hears from us before we test, with the checks we will run.

  3. Run the same checks

    Every app on our own test site, with the same pages and the same scripts.

  4. Makers see results first

    Each maker has three working days to correct a fact or object.

  5. Publish and correct

    What each app does and does not do, free to read. Mistakes are fixed in the open.
