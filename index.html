How a comparison is made

  1. We pick a feature request that several look-alike apps claim to answer.
  2. We tell each maker before we start.
  3. We install every app on our own test site and run the same checks on each.
  4. Each maker sees their results first and can correct or object.
  5. We publish what each app does and does not do, and correct mistakes in the open.
